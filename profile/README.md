# 🌎 Horizon Earth

**Tecnologia para compreender o planeta e facilitar o acesso a informações sobre desastres naturais e clima.**

Somos uma equipe de estudantes de Informática do IFCE — Campus Maranguape. Desenvolvemos o Horizon Earth como projeto acadêmico de Programação Orientada a Objetos.

## Nossa proposta

Criar uma aplicação desktop em JavaFX com um planeta 3D interativo. Ao selecionar uma região, o usuário poderá consultar informações sobre clima e desastres naturais obtidas por APIs. O sistema também terá autenticação obrigatória e uma agenda de contatos.

A consulta por região e a integração entre os módulos são objetivos do projeto. Os repositórios representam etapas distintas do desenvolvimento.

## Desenvolvimento

O protótipo do planeta utiliza JavaFX 3D, rotação, zoom e texturas. A agenda e o login são desenvolvidos como módulos próprios, com integração prevista no aplicativo principal. Também mantemos protótipos de interface e uma implementação de login em Swing como material de desenvolvimento.

Java, programação orientada a objetos, JavaFX, Git e GitHub compõem a base do projeto. A persistência em banco de dados e os provedores de APIs serão documentados conforme forem definidos e integrados.

## Missão

Apresentar informações ambientais de forma visual e compreensível, aplicando tecnologia, aprendizado e trabalho em equipe.
