# Perfil da Horizon Earth

Este repositório mantém a apresentação da organização no GitHub.

| Arquivo | Finalidade |
| --- | --- |
| `profile/README.md` | Apresentação exibida na página da organização |
| `README.md` | Instruções de manutenção deste repositório |
| `LICENSE` | Licença MIT da documentação própria |

Para exibir o perfil público, o repositório deve se chamar `.github`, ser público e conter `profile/README.md` na branch padrão. Atualize os links e o estado dos projetos conforme o desenvolvimento avançar.

## Contribuição

Crie uma branch para a alteração, faça commits claros e abra um pull request. Confira a execução e os testes disponíveis antes de integrar à `main`.

## Licença

Código e documentação próprios da Horizon Earth distribuídos sob a [licença MIT](LICENSE). Materiais externos, imagens, texturas e dados de APIs mantêm suas licenças e atribuições originais.

## 🏢 Estrutura de toda a organização

Cada item abaixo é um repositório independente, não uma branch nem uma subpasta de um único projeto. O guia prevê login, agenda e projeto livre; os demais repositórios apoiam planejamento, identidade visual e experimentação.

| Repositório | Papel |
| --- | --- |
| [Design](https://github.com/Horizon-Earth/Design) | Identidade visual e propostas de telas. |
| [Agenda_Contatos](https://github.com/Horizon-Earth/Agenda_Contatos) | Agenda e persistência MySQL. |
| [.github](https://github.com/Horizon-Earth/.github) | Perfil e documentação da organização. |
| [LoginSystem](https://github.com/Horizon-Earth/LoginSystem) | Login em JavaFX. |
| [SistemaLogin](https://github.com/Horizon-Earth/SistemaLogin) | Implementação de login em Swing. |
| [HorizonSoftware](https://github.com/Horizon-Earth/HorizonSoftware) | Apresentação e planejamento geral. |
| [demo-repository](https://github.com/Horizon-Earth/demo-repository) | Experimentos HTML e workflows. |
| [Terra3d](https://github.com/Horizon-Earth/Terra3d) | Projeto livre: planeta 3D em JavaFX. |
